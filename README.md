# Gerador Mega Sena

## Project Overview
Gerador Mega Sena is a web-based application designed to generate random lottery numbers for Brazil's popular lottery game, Mega Sena. It allows users to select the number of lottery numbers to generate and a future date for their lottery play, providing a fun and interactive way to participate in the lottery.

## Installation
To set up the project locally, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/gerador-mega-sena.git
    cd gerador-mega-sena
    ```

2. **Open the `index.html` file** in your web browser:
   - Simply double-click `index.html` to view the application.

**Note**: There are no additional dependencies to install as this project uses CDN for styles and scripts.

## Usage
1. Select the quantity of numbers you would like to generate (6, 8, 12, or 18).
2. Choose a future date for your lottery play.
3. Click the "Gerar Números da Sorte" button to generate your lottery numbers.
4. The generated numbers will be displayed along with some probability analysis.

## Features
- User-friendly interface using Tailwind CSS for styling.
- Dynamic number generation with an option to select the quantity.
- Real-time probability analysis based on generated numbers.
- Responsive design that works well on various devices.

## Dependencies
This project includes the following external dependencies:
- [Tailwind CSS](https://tailwindcss.com/)
- [FontAwesome](https://fontawesome.com/) for icons.

These libraries are loaded via CDN links directly in the `index.html` file.
